## 1. 这是什么

面向终身学习者的**心智模型学习站**。它的立场很明确：市面上的「思维模型」内容大多是励志化的知识索引，读完觉得懂了，用的时候一个也调不出来。

本站的做法是把每张卡压成一套**带硬校验的八字段模板**，其中两个字段是反向的：

- **误用陷阱** —— 人们通常怎样把它用错；
- **不适用边界** —— 什么条件下这个模型失效，**必填，不得写「视情况而定」**。

并且**不设「优点」字段**。理由是：模型是工具不是立场，写优点会诱导用户在所有场景下调用它——恰恰是误用之源。

### 当前版本的性质

- 单文件纯前端，双击 `index.html` 即可运行，**不含任何外部网络请求**；
- 首批 **10 张完稿示范卡** + 站点内登记的 **100 条模型索引**（含学科与完稿状态）；
- 每日一练与「我的组合」存档保存在浏览器 **localStorage** 中。

## 4. 卡片模板（Card Schema v1.0）

一张卡 = 8 个字段，固定顺序、固定字数配额。**任何一张卡缺字段即视为未完稿。**

| # | 字段 | 配额（字） | 写法要求 | 硬校验 |
|---|---|---|---|---|
| 01 | 模型名 | ≤ 20 | 中文名 + 英文原名，别称写进括号 | 不得含「法则/定律」以外的夸张后缀 |
| 02 | 定义 | ≤ 60 | 只陈述机制与变量关系，不写价值判断 | 禁含「帮你」「让你」「才能」 |
| 03 | 来源学科 | ≤ 12 | 填 1–2 个**原生**学科，不填应用领域 | 必须是该模型的原生学科 |
| 04 | 作用机制 | ≤ 70 | 必须写成「因为 X 变化 → 经 Y 传导 → 所以 Z」的因果链 | 无因果链算缺字段 |
| 05 | 迁移案例 ×3 | 每条 ≤ 45 | 跨 ≥ 2 个学科；每条含可核查锚点（机构/年份/公开数据） | 无锚点即判虚构，退回重写 |
| 06 | 误用陷阱 | ≤ 40 | 写「人们通常怎样把它用错」 | 必须是具体的错误动作 |
| 07 | 不适用边界 | ≤ 40 | 写清在什么条件下失效或不应被调用 | **必填**，不得为空或写「视情况而定」 |
| 08 | 关联模型 | ≤ 3 个 | 每个注明关系类型：上游/下游/约束/对立/互补 | 禁止同义模型并列 |

**配额总计** ≈ 385 字，留 15 字浮动，正文严格 ≤ 400 字。

### 三条设计说明

1. **为什么迁移案例必须是 3 条且跨学科**：1 条是例子，2 条是巧合，3 条且分布在不同学科，才能把模型从「某个领域的说法」逼成「结构」。同一学科内的 3 条不算达标。
2. **为什么不设「优点」字段**：见上文——模型是工具不是立场。
3. **为什么关联模型上限是 3 个**：超过 3 个会形成语义糊团，用户无法据此导航。关系图谱只承认卡片中声明过的边。

### 可迁移性自检（写完后对每张卡问三句）

- 换一个学科，机制句中的变量还成立吗？（不成立 → 机制写窄了）
- 三个案例的失败态能枚举吗？（不能 → 边界可能写漏）
- 有没有人会在我写的「不适用边界」里误用它？（有 → 陷阱写偏了）

## 5. 首批 10 张示范卡

| # | 模型 | 来源学科 |
|---|---|---|
| 01 | 复利效应（Compound Interest） | 数学 / 金融学 |
| 02 | 临界点（Tipping Point） | 物理学（相变）/ 复杂系统科学 |
| 03 | 机会成本（Opportunity Cost） | 经济学 |
| 04 | 二阶思维（Second-Order Thinking） | 系统工程 / 决策理论 |
| 05 | 路径依赖（Path Dependence） | 制度经济学 / 演化生物学 |
| 06 | 熵增（Entropy Increase） | 热力学 / 统计力学 |
| 07 | 边际递减（Diminishing Marginal Returns） | 经济学 / 农学 |
| 08 | 安全边际（Margin of Safety） | 工程学 / 价值投资 |
| 09 | 反馈回路（Feedback Loop） | 控制论 / 系统动力学 |
| 10 | 逆向思维（Inversion） | 数学（反证与反演）/ 工程可靠性 |

10 张卡实测 281–365 字，全部 ≤ 400 字；30 条案例全部带机构 / 年份 / 公开数据锚点；涉及学界争议的（如 QWERTY）已在卡内标注争议，不作断言。

### 逆向思维 × 二阶思维：边界区分

两者都要求「多想一步」，常被混用。区别**不在深浅，而在方向与依赖条件**：

| 维度 | 二阶思维 | 逆向思维 |
|---|---|---|
| 方向 | 沿时间向前：做了 A → 然后呢 → 再然后呢 | 调转方向：要输掉该怎么做？然后不做 |
| 输出物 | 连锁后果的预判清单（会发生什么） | 禁止项清单（绝不做什么） |
| 依赖条件 | 因果链可推断 | 失败态可枚举、边界清晰、有前例 |
| 典型失效 | 推得太远，置信度衰减却仍等权下注 | 漏枚举关键失败项；把「不失败」当成「已成功」 |

**判据一句话**：能说清「接下来会怎样」，用二阶思维；能说清「怎样一定会输」，用逆向思维。
**组合顺序**：先逆向列禁止项缩小方案空间，再对剩下的少数方案做二阶推演。反过来做会浪费算力。

## 8. 硬约束（设计红线）

1. **禁止成功学鸡汤与励志语录** —— 不出现「让你更强」「改变人生」「底层逻辑秒杀」等表述；
2. **每个模型必须写「不适用边界」** —— 不得只讲优点；
3. **关联模型 ≤ 3 个**，且不得为同义替换模型；
4. **迁移案例必须可核查** —— 含主体 / 时间 / 数据锚点，不得虚构。
